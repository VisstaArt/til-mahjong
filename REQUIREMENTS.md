# Требования: Модуль фраз и грамматики
**Версия:** v1.0 · **Обновлено:** 2026-08-05

## Must Have — Sprint 1 (квиз фраз из разговорников)
- REQ-001: Извлечь фразы + переводы из предоставленных PDF-разговорников в структурированные данные (JS/JSON), сохранив разбивку на тематические блоки как в оригинале.
- REQ-002: Экран квиза — фраза на одном языке (RU или TR), 8 вариантов перевода, тап на правильный.
- REQ-003: При правильном ответе — озвучка турецкой фразы (переиспользовать `speak()` из script.js).
- REQ-004: Кнопка «подсказка» — показывает подсказку; ответ с подсказкой НЕ засчитывается в прогресс.
- REQ-005: Прогресс по фразам — переиспользовать/расширить систему `PROGRESS_BOXES`/streak (script.js), отдельно от прогресса по словам.
- REQ-006: Каталог тем — экран со списком тематических блоков разговорника (по аналогии с catalog.html), выбор темы → квиз по фразам этой темы.

## Should Have
- REQ-010: Дистракторы (7 неверных вариантов) подбирать из фраз того же тематического блока — правдоподобные, а не случайные из всей базы.
- REQ-011: Чередование направления показа (RU→TR / TR→RU) в рамках одного прохода темы.

## Could Have
- REQ-020: Общий счётчик выученных фраз на экране каталога (по аналогии с уже сделанным для слов).

## Won't Have v1 (сознательно откладываем — Sprint 2+)
- Контекстные диалоги с ИИ-генерацией на лету.
- Тренировка суффиксов/грамматики через механику «тайл-кандидат ищет пару к карточке контекста».
- Упражнение на порядок слов.
- Драг-механики, ввод текста с клавиатуры.
