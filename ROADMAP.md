## Спринт 1: Квиз фраз из разговорников — Готово (MVP)
**Цель спринта:** рабочий MVP квиза по фразам из русско-турецких разговорников, с озвучкой, подсказками, прогрессом и каталогом тем, удобный на телефоне.
**Готово когда:** на телефоне можно выбрать тему из каталога и пройти квиз минимум по одному тематическому блоку — с озвучкой правильных ответов и сохранением прогресса между сессиями. ✅ Проверено в браузере на мобильном разрешении (390×844) — работает, ошибок в консоли нет.
- [x] Получить PDF-разговорники от пользователя, оценить формат (текстовый слой / скан)
- [x] Выбрать основной источник: «Популярный русско-турецкий разговорник» (225 стр.) + «Устойчивые выражения со словом Allah» (225 идиом, прочитаны вручную по картинкам страниц).
- [x] REQ-001: Данные собраны в `assets/seed/phrases.json` — 22 темы, 1118 фраз.
- [x] REQ-006: Каталог тем — вкладка «💬 Фразы» в шапке, экран `screen-phrases-catalog`, плитки в духе каталога слов.
- [x] REQ-002: Экран квиза `screen-quiz` — фраза + 8 вариантов, тап на ответ.
- [x] REQ-003: Озвучка при правильном ответе (переиспользован `speak()`).
- [x] REQ-004: Подсказка — гасит половину неверных вариантов, ответ после подсказки не идёт в прогресс.
- [x] REQ-005: Прогресс по фразам — отдельное хранилище `mahjong-phrase-progress`, система "ящиков" как у слов.
- [x] REQ-010: Дистракторы из той же темы (с добором из других тем, если фраз мало).
- [x] REQ-011: Направление RU→TR / TR→RU чередуется случайно на каждый вопрос.

**Известный остаток:** ~9% фраз в датасете (в основном в «Приветствие», «Здоровье» и подобных темах с короткими репликами без знаков препинания) — слипшиеся при автоматическом разборе PDF записи с посторонним текстом (например обрывок «Русско-турецкий разговорник» затесался в один из вариантов ответа). Не блокирует использование, но стоит почистить по мере обнаружения — данные всего в одном JSON-файле, править точечно.
