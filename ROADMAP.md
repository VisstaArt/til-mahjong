## Уровни A1 → B2 — общий план для всего сервиса (решено 2026-09-27)
Согласовано с пользовательницей и агентом диалогов (сессия mahjong-prototype-bd).

**Главный принцип:** сложность растёт постепенно. Не слишком сложно в начале — иначе
«мозг не хочет это делать» — и не слишком просто, чтобы был рост.

**Спиральная программа** (как в Yeni Hitit / English File): тема не принадлежит одному
уровню, а возвращается на каждом, с более богатым языком. Знакомство A1 — «меня зовут,
я из Москвы, я работаю»; Знакомство A2 — «я переехала в прошлом году, раньше жила…»;
B1 — «переехала, потому что…, если хочешь — познакомлю»; B2 — оттенки и сложные предложения.

**Путь:** уровень → темы уровня → внутри темы по порядку: фразы → грамматика → диалоги.
Путь подсказывает порядок («что дальше»), но **«Фразы» и «Диалоги» не блокируются**:
`level` там — информационное поле (бейдж, фильтр), все опубликованные темы открыты.
**Жёсткий уровень — только внутри «Грамматики»:** тема открывается после предыдущих,
а на ступени «В жизни» фраза/реплика берётся, только когда пройдены все её правила.

| Уровень | Темы (черновик) | Грамматика, которую уровень вводит |
|---|---|---|
| A1 | Знакомство, Семья, Кафе и еда, Покупки, Город и дорога, Мой день | гармония, -lar; «быть» (-(y)ım), var/yok, mı; -de/-den/-e; -yor; притяжание (benim evim, Olga'nın); винительный -(y)ı; -di; istemek + инф., -meli, повелительное; -ecek |
| A2 | снова Знакомство, Покупки, Кафе + Путешествие, Отель, Здоровье, Погода | -ir (широкое), -miş, -ebil, -ken, -ince, -meden/-ip, сравнения |
| B1 | Работа, Жалобы и проблемы, Мнения, Бизнес: встречи и офис | причастия -dığı/-en/-eceği, залоги (-dır/-t, -ıl, -ın, -ış), условное -se |
| B2 | Переговоры, Финансы, Право (бизнес-разделы разговорника) | -mış gibi, -dıkça, косвенная речь, сложные предложения |

**Поле `level`** («A1»…«B2») у каждой фразы (assets/phrases) и реплики/диалога
(assets/dialogues). Лишнее поле существующий код игнорирует; `tr` не трогаем — по нему
ключ прогресса фраз.
- Черновую оценку даёт `tools/grammar/levels.py` (по самому сложному правилу, эвристика
  по окончаниям — с ошибками, поэтому только черновик), проверяет и правит агент диалогов.
- Застывшие формулы (Tanıştığıma memnun oldum, rica ederim, özür dilerim, görüşürüz,
  вежливые «…alabilir miyim? / …verir misiniz?») считаются уровнем, на котором их учат
  целиком — A1, без требования знать их грамматику.
- Уровень диалога — по его репликам, но с учётом формул; 1–2 реплики чуть выше уровня
  допустимы, если смысл понятен из контекста.

**Готовый контент не выбрасываем, а раскладываем по слоям.** Сейчас (6 тем, 161 диалог)
76% реплик — A1, 19% — A2, 4% — B1; почти в каждом диалоге 2–4 реплики выше A1.
Шаги: разметить уровни → диалоги уходят в слои A1/A2 своей темы → в первых темах A1
упростить реплики, которые без нужды сложнее (например «Daha yavaş konuşursanız,
anlayabilirim» → «Lütfen yavaş konuşun») → дописать недостающие простые диалоги A1.

**Грамматика внутри темы — три ступени:** База (свои короткие фразы A1 на частых словах,
с героями из assets/dialogues/LEGEND.md) → Вперемешку (с уже пройденными правилами) →
В жизни (фразы разговорника и диалогов, если пройдены все их правила).

**Кто что делает:**
- агент диалогов — фразы, диалоги, герои и стиль (LEGEND.md); новые диалоги пишет под целевой уровень этого раздела и проверяет на соответствие уровню и легенде;
- агент грамматики — темы и памятки, генератор форм (tools/grammar), проставление `level` в assets/phrases и assets/dialogues своим разметчиком, «База», экран пути по уровням.

**Правила правки общих JSON:** `level` добавляется точечно, с сохранением текущего стиля
файла (диалоги — компактно, реплика на строку; без полного json.dump с indent — иначе
diff на тысячи строк). `tr` и `ru` не менять (ключ прогресса `${topicId}::${tr}`);
найденные ошибки в тексте — списком агенту диалогов.

**Порядок работ:**
1. [ ] «База» A1 для -yor и -de/-den/-e + ступени внутри темы грамматики.
2. [ ] Проставить `level` во фразах и диалогах (разметчик + ручная проверка спорного).
3. [ ] Новые диалоги — под целевой уровень; простые диалоги A1 для первых тем.
4. [ ] Экран пути: уровень → темы → фразы / грамматика / диалоги, открытие по порядку.
5. [ ] Остальные темы грамматики A1 по порядку из таблицы.
