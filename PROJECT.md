# Модуль фраз и грамматики (расширение mahjong-prototype)
**Создан:** 2026-08-05 · **Статус:** Активный
**Тип:** обучающий + технический

## Суть
Новый обучающий модуль внутри существующего приложения mahjong-prototype. Если сама игра mahjong тренирует отдельные слова (пары слово—перевод), этот модуль идёт дальше: тренировка готовых фраз/предложений, а в перспективе — грамматики и суффиксов, то есть перехода от «знаю слова» к «умею говорить». Личный инструмент, используется на телефоне.

## Сильная сторона
ДНК существующей игры: тап-механики без драга, без давящей геймификации (нет таймера-давки, нет штрафов/жизней как в Duolingo), медитативный/спокойный темп, взвешенная система прогресса по «коробкам» (Лейтнер-подобная — `PROGRESS_BOXES` в script.js). Новый модуль обязан наследовать эту философию, а не превращаться в обычный quiz-апп. Именно это отличает подход пользователя от типовых языковых приложений, которые ей не заходят.

## Целевая аудитория
Только сама пользовательница — личный инструмент, не продукт для внешней аудитории. Обязательно должен нормально работать на телефоне (мобильный браузер).

## Критерии успеха (v1 — квиз фраз)
Можно открыть на телефоне, выбрать тему из каталога, пройти квиз по фразам из разговорника с озвучкой правильных ответов, прогресс сохраняется между сессиями.

## Ключевые решения и принципы
- Тап, не драг. Без ввода текста с клавиатуры (турецкие спецсимволы ğ/ı/ş/ö/ü/ç неудобно печатать на телефоне).
- Переиспользовать существующую инфраструктуру, а не изобретать заново:
  - `speak()` (script.js) — озвучка через браузерный TTS.
  - Система прогресса `PROGRESS_BOXES` / `getWordBox` / `bumpWordStreak` (script.js) — база для прогресса по фразам.
  - Паттерн «каталог по темам» (`catalog.html`, `wordsByCategory`) — база для каталога тем фраз.
  - Паттерн «OpenAI-ключ в браузере, ничего не уходит кроме api.openai.com» (wordbank.js) — пригодится для будущей ИИ-генерации контекстных диалогов (Sprint 2+).
- v1 контента — из готовых русско-турецких разговорников (PDF, источник — пользователь), НЕ требует ИИ-генерации. Разговорники уже разбиты на тематические блоки — использовать эту структуру для каталога тем.
- v2+ (отложено) — контекстная тренировка суффиксов/грамматики: карточки с ситуацией/диалогом + пропуском, тайлы-кандидаты рядом, тап на подходящий по контексту вариант. Решает проблему из обсуждения: правильность турецкого суффикса зависит от контекста (времени, ситуации), поэтому абстрактный матчинг «тайл=тайл» без контекста нечестен — нужна привязка к конкретной ситуации.

## Риски
- Сканы PDF без текстового слоя → нужен OCR → ошибки в диакритике, нужна ручная проверка перед тем, как класть во фразы игры.
- 8 вариантов ответа на маленьком экране телефона — нужна компактная вёрстка, иначе не влезет.
- (Для v2, на будущее) Неоднозначность порядка слов в турецком из-за акцента — решается тем, что каждое упражнение привязано к конкретному контексту/ситуации, а не абстрактно.

## Ограничения
Тот же стек, что у mahjong: vanilla JS/HTML/CSS, localStorage/IndexedDB, без бэкенда, оффлайн-first на телефоне.
