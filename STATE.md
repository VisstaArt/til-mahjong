- Реализована вкладка «💬 Фразы»: переключатель режимов в шапке (`index.html`), экран каталога тем `screen-phrases-catalog`, экран квиза `screen-quiz` (`phrases.js`, стили в `style.css`).
- Квиз: фраза + 8 вариантов (тап на ответ), направление RU↔TR чередуется случайно, дистракторы из той же темы, подсказка гасит половину неверных и не засчитывается в прогресс, озвучка через переиспользованный `speak()`, прогресс — отдельное хранилище `mahjong-phrase-progress` по системе "ящиков" (как у слов).
- Проверено в headless-браузере на мобильном разрешении (390×844): каталог → квиз → ответ → подсказка → возврат в каталог — всё работает, ошибок в консоли нет. Скриншоты подтвердили нормальную вёрстку 8 вариантов на маленьком экране.
- Тема «Вопросительные слова» вычищена от одиночных слов, «hangi» (какой) добавлено в базу mahjong (`assets/seed/pending-words.json`).
- По просьбе пользователя данные фраз разбиты на манифест + файл на тему (`assets/phrases/manifest.json` + `<id>.json`) — темы подгружаются по требованию, как категории слов. Добавлен экран темы (`screen-phrase-topic`) с чекбоксами "брать в практику" (хранилище `mahjong-phrase-excluded`) и кнопкой "✓ Знаю" (сразу помечает фразу выученной) — полный аналог `buildWordRow`/`screen-category`.
- Найдена и починена настоящая причина "не обновляется на телефоне": GitHub Pages отдаёт файлы с `Cache-Control: max-age=600`, и `fetch()` в `sw.js` тихо брал ответ из HTTP-кеша браузера вместо сети — "network-first" был таким только на словах. Добавлен `cache: "reload"` в fetch-запрос сервис-воркера + поднята версия кеша (`til-mahjong-v4`).
- Пользователь заметил приём для чистки данных: если в русском и турецком тексте фразы одинаковое число слов с заглавной буквы — это признак нескольких слипшихся фраз в одной записи, можно резать по этой границе. ## Открытые вопросы
- Остаточные слипшиеся/битые фразы всё ещё могут попадаться (разрез по заглавным буквам не панацея — например список слов без единой заглавной буквы вообще не ловится). Чинить точечно по мере обнаружения, как в этот раз — данные лежат по темам в `assets/phrases/*.json`, найти нужную запись просто.
- ~84 фразы, отложенные на самом первом проходе очистки (до появления приёма с заглавными буквами), потеряны вместе со scratchpad-файлом — при желании можно заново вытащить из исходного PDF и попробовать разрезать тем же приёмом.
- Приложение теперь двурежимное — заголовок сокращён до «Тил» (без «Маджонг»), но манифест PWA (`manifest.json`, `name`/`short_name`) и `<title>` пока не обновлены под новое позиционирование — мелкий косметический долг.
- Книга «4 книги в одной» (словари + грамматика) — не тронута с момента расшифровки шрифта, ждёт своей очереди для пополнения слов mahjong и материала под Спринт 2.
