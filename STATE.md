## Только что завершили
- **Ручная чистка данных завершена полностью.** Все 57 фраз, не разобранных автоматически (сначала по пунктуации, потом по заглавным буквам), пользователь прислала построчно с исправлениями — разобраны и добавлены в темы: Вопросительные слова, Приветствие, Профессии (→ ушли в базу mahjong, не во фразы), Как поменять деньги, В отеле, Ресторан, Путешествие, Осмотр достопримечательностей, Покупки/сервис, Знакомство, О погоде, Выражения для бизнесмена, Развлечения, Здоровье. Итог: **1745 фраз в 22 темах** (было 1118 после автоматической чистки). `_review_needed.json` удалён — больше не нужен.
- В базу mahjong (`pending-words.json`) по пути добавлено ~24 новых слова из профессий, которые пользователь явно попросила отправить туда, а не во фразы.
- Добавлена плашка с фразой при правильном ответе в квизе — по образцу `showMatchPopup` из mahjong: карточка с турецкой фразой, переводом и кнопкой "🔊 Повторить", закрывается тапом по фону или сама через 4,5 сек, потом сразу следующий вопрос. Переиспользован существующий `#match-popup`.
- По просьбе пользователя данные фраз разбиты на манифест + файл на тему (`assets/phrases/manifest.json` + `<id>.json`) — темы подгружаются по требованию, как категории слов. Добавлен экран темы (`screen-phrase-topic`) с чекбоксами "брать в практику" (хранилище `mahjong-phrase-excluded`) и кнопкой "✓ Знаю" — полный аналог `buildWordRow`/`screen-category`.
- Найдена и починена настоящая причина "не обновляется на телефоне": GitHub Pages отдаёт файлы с `Cache-Control: max-age=600`, и `fetch()` в `sw.js` тихо брал ответ из HTTP-кеша браузера вместо сети. Добавлен `cache: "reload"` в fetch-запрос сервис-воркера + поднята версия кеша (`til-mahjong-v4`).
- Приём чистки данных "разрез по заглавным буквам" (если в RU и TR одинаковое число слов с заглавной буквы — это склеенные фразы) прогнан по всем темам: 1126 → 1280 фраз. Тему идиом Allah пришлось откатить — там каждое выражение само по себе начинается с "Allah".

## Открытые вопросы
- Приложение теперь двурежимное — заголовок сокращён до «Тил» (без «Маджонг»), но манифест PWA (`manifest.json`, `name`/`short_name`) и `<title>` пока не обновлены под новое позиционирование — мелкий косметический долг.
- Книга «4 книги в одной» (словари + грамматика) — не тронута с момента расшифровки шрифта, ждёт своей очереди для пополнения слов mahjong и материала под Спринт 2.
- В паре мест переводы содержат несколько синонимов через запятую/слэш (например "процент" → "yüzde, faiz") — в квизе показываются как есть одной строкой, это осознанный выбор, не баг.
