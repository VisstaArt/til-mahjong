# Состояние: Модуль фраз и грамматики
**Обновлено:** 2026-08-07

## Фразы — «Пароход» и карта пути (2026-10-14)
- В рейсе только целые фразы: тур→рус, рус→тур, на слух; 6 вариантов ответа.
- В работе до 20 начатых фраз (`PHRASE_WORKING_SET`), 3 верных ответа → 🟡 «запомнилась», её место сразу занимает следующая по пути. 🟡→🟢 на следующий день, 🟢→⭐ через 3 дня, дальше проверки через неделю/месяц/3 мес. Не подошёл срок — фраза в рейсы не попадает. Ошибка на совсем новой фразе корпус не ломает.
- Голос (speech.js, Web Speech API — бесплатно): перед первым рейсом дня спрашиваем «Сейчас можно говорить вслух?»; «да» — задания «Скажи по-турецки вслух» вместо части «Как сказать по-турецки». Сверка мягкая: без точек над буквами, допуск 1–2 буквы на слово, цифры словами, «a/b» — любое, «(…)» — необязательно, «…» — своё слово; короткая фраза — все слова, длинная — 3/4. Не совпало — видно, что услышал телефон, ещё попытка или «показать ответ» → «я так и сказала» (засчитать) / «не так». Отказ распознавания — голос выключается, вопрос становится выбором.
- Карта пути в каталоге: уровень = маршрут по Стамбулу, причал ≈ 15 фраз подряд (темы в порядке levels.json), пароход = первый причал, где не все фразы хоть раз запомнились (`ever`). Сверху — сколько осталось до причала и до конца уровня в рейсах. На экране рейса слева/справа — текущий и следующий причал.

## Игры со словами (2026-10-14, wordgames.js)
- В каталоге слов — полоса «🎮 Игры с выбранными словами»: Маджонг + 🌧 «Слова падают» (поймать нужное турецкое слово по картинке/переводу, каждое третье — на слух; 3 жизни, 20 слов, ускоряется), 🔎 «Найди слова» (сетка 8×8, слова →/↓/↘, подсказки картинкой/переводом, выделение пальцем или тапом первой и последней буквы), ✏️ «Кроссворд» (5–7 слов, своя клавиатура с турецкими буквами, слово проверяется сразу), 👂 «Слушай и найди» (звучит слово — выбрать из 6 картинок; если слов с картинками ≥ 12 — только они).
- Слова — те же, что для маджонга (getActiveDeck), невыученные чаще; каждый ответ — bumpWordStreak. Рекорды — `mahjong-wordgames-best` (локально).

## Занятие дня (2026-10-14, today.js)
- Кнопка «📅 Занятие дня» под вкладками. Тема дня = тема причала, у которого пароход на карте фраз (journeyLevel), фиксируется на день (`phraseProgress.__day`, синхронизируется).
- Шаги: 1 слова темы (маджонг по категориям `DAY_TOPIC_WORDS`, слова уровня, без трогания своих галочек — `dayDeckOverride`) → 2 два рейса по фразам темы → 3 раунд грамматики (следующая ступень её пути — правила к темам не привязаны) → 4 диалог темы (первый неосвоенный этого уровня; у «Приветствия» своих нет — берётся следующая тема с диалогами).
- Конец шага сообщают режимы через `dayBlockDone(...)`; внизу всплывает «✓ Шаг готов — к занятию дня». Все 4 — «Сегодня всё!», серия дней подряд. Нажатие на вкладку режима выходит из занятия.

## Диалоги — лесенка (2026-10-14)
- Каждый проход диалога за ту же роль — ступенью выше (`phraseProgress.__dialogues`, синхронизируется): 1 «Понять» (выбор нажатием) → 2 «Выбрать голосом» (варианты на экране, сказать нужный) → 3 «Вспомнить с подсказкой» (по-русски + первые буквы) → 4 «Живой разговор» (без подсказок). Дальше ступень, если ошибок ≤ четверти своих реплик (минимум 1 прощается).
- Сверка на 3–4: главные слова (без lütfen/efendim/имён), допустимые варианты `turn.alts` (пока пусто — пополнять по присланным ответам), не совпало — «сказала по-другому, но правильно» (засчитывается, пишется в `mahjong-dialogue-said`, кнопка «📋 Мои ответы по-другому» в каталоге) / «не вспомнила». Без голоса — вспомнить про себя и проверить себя.
- Во «Фразах» голос — только для фраз от 🟡 (решение пользовательницы).

## Грамматика A1 — пути тем (на 2026-10-10)
- 9 тем по порядку, каждая — путь из 9–12 ступеней (tools/grammar/path-*.txt), всего ~850 своих фраз + фразы «В жизни» из «Фраз»/«Диалогов»: -yor → падежи -de/-den/-e → «быть» → «чей?» → винительный → прошедшее -dı → «хочу, надо, сделайте» → будущее -ecek → «с кем? чем?» -la. Следующая тема открывается ступенью «Всё вместе» предыдущей.
- Игра: «Собери из кучки» + спасение Памук (пирамида, 2–3 ошибки, взрыв), подсказки копятся за спасения и объясняют ровно один следующий кусочек.
- Генератор форм — tools/grammar/morph.py (самопроверка `python3 tools/grammar/morph.py`), разметчик — tools/grammar/build.py (после правок фраз/диалогов — перезапустить).

## Раздел «Грамматика» (2026-09-27)
- Новая вкладка 🧩 Грамматика (`grammar.js`): тема = одно правило. Сначала памятка на экран, потом упражнения на фразах из «Фраз» и «Диалогов». Методика взята из рабочей тетради Yeni Hitit 1: смысл → форма.
- ~~«Выбери форму» / «Собери слово» рядами~~ — пользовательница: скучно, непонятно сколько осталось. 2026-09-30 заменено игрой **«Собери из кучки»**: фраза с пропуском + кучка плашек в стиле маджонга (корни, окончания, целые слова, «почти правильные» обманки), тап по порядку. Ступени: одно слово → два → три → вся фраза по переводу → «В жизни». Раунд 8 фраз с точками прогресса, звёзды, следующая ступень за 2★ (`mahjong-grammar-levels`). Картинки-«паровозик» отвергнуты как детское; текст↔текст в маджонге отвергнут — без картинок не запоминается.
- Темы: -yor (449 пропусков), -de/-den/-e (149). «Повторение вперемешку» открывается после 20 ответов в каждой теме, в нём до 2 пропусков разных тем в одной фразе.
- Все формы готовятся офлайн: `tools/grammar/morph.py` (генератор, самопроверка `python3 tools/grammar/morph.py`) → `tools/grammar/build.py` → `assets/grammar/items.json`. Разметка засчитывается, только если генератор даёт ровно ту же форму, что во фразе. Недостающие глаголы — `tools/grammar/extra-verbs.txt`.
- Прогресс: свои ящики + статистика по правилам (`mahjong-grammar-rules`), слабые правила попадаются чаще.
- Долг: ключи `mahjong-grammar-*` пока не синхронизируются с Supabase (нужны новые колонки в user_progress).
